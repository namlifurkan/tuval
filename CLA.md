# Contributor Licence Agreement

Tuval is AGPL-3.0-or-later. The project also needs to be able to offer the same code under other
terms — a hosted service, or a licence for a company that cannot take AGPL. A contribution that
arrives under AGPL alone cannot be included in either, which would mean maintaining two versions
of the same file forever.

So every contributor signs this once, before their first pull request is merged. It is not a
transfer of ownership: **you keep the copyright in what you wrote.**

## How to sign

Add a line to [`CONTRIBUTORS.md`](CONTRIBUTORS.md) in your first pull request:

```
Name <email> — GitHub @handle — signed CLA <YYYY-MM-DD>
```

That commit, signed with your own account, is the record. There is no form to fill in and no
service to sign up for.

## Why a CLA and not a DCO

A DCO certifies the right to submit under the project's existing licence. It gives no permission
to relicense, which is exactly the permission this project needs to keep the hosted service and
the repository as one codebase. A DCO here would leave the project unable to do the thing it is
being built to do.
